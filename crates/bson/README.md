# xmlcraft-bson

BSON for XmlCraft (layer L1, no UI, no I/O, compiles for the web): a codec and the text a BSON file is shown as.

- **Codec** (`read_all`, `write_all`): the documents of a `.bson` file (a series of documents) and back. Every type of the specification is kept — double, string, document, array, binary with its subtype, undefined, ObjectId, boolean, date, null, regular expression, DBPointer, JavaScript, symbol, JavaScript with scope, int32, timestamp, int64, decimal128, min and max key — so what is read is written again **byte for byte**. Reading is strict about what makes bytes ambiguous (lengths that disagree, a string that is not UTF-8, a missing terminator, an array whose names are not `0`, `1`, `2` …, a boolean that is neither 0 nor 1, an unknown type) and says at which byte; documents may nest 100 levels, and nothing allocates more than the input is long.
- **Text projection** (`to_text`, `from_text`): MongoDB Extended JSON v2. *Canonical* spells out every type (`{"$numberInt": "7"}`, `{"$oid": "…"}`, `{"$date": {"$numberLong": "…"}}`, `{"$numberDecimal": "12.50"}` …), which is what makes the text turn back into the same bytes; *relaxed* writes plain numbers and ISO dates where nothing visible is lost. One document is indented over lines; several are one to a line (a dump of a million documents is a text of a million lines). `from_text` reports every problem with its place in the text: a syntax error, or a value that is not valid Extended JSON (an `$oid` that is not 24 hex digits, a `$date` that is no date, base64 that is not base64 …).
- **Decimal128** is converted to and from its string form with the rules of the General Decimal Arithmetic specification (`12.50` stays `12.50`, `1E-7` stays `1E-7`).
- **Not here:** BSON that is not canonical in a way the model cannot hold (a NaN with a payload other than the usual one, an array with irregular names) is refused or normalised, not carried; the window, the document and the tools come in the next task.

Tests: `tests/roundtrip.rs` (the examples of the specification, every type through bytes and canonical text, relaxed text, layouts, errors with places, damaged bytes of every kind never panic, random documents survive bytes → text → bytes exactly).
