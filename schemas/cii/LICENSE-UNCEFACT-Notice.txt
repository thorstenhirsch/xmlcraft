The schemas in this folder are the XML Schema modules of the UN/CEFACT Cross Industry Invoice, version 100.D16B (Supply Chain
Reference Data Model subset, decoupled code list schema modules), schema date 10 October 2016, in the copy that the CEN validation
artefacts for EN 16931 validate against (https://github.com/ConnectingEurope/eInvoicing-EN16931, tag validation-1.3.17,
cii/schema/D16B SCRDM (Subset)/uncoupled clm/CII/uncefact/data/standard/). They are not modified. Each carries the notice that
follows, which allows them to be copied and furnished to others provided that they are not modified.
